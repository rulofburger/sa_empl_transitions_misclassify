# Employment Transitions with Misclassification: Evidence from South Africa

**Paper**: *Estimating employment transitions while accounting for classification error: evidence from South Africa*  
**Authors**: Zander Prinsloo, Cobus Burger, Rulof Burger, Dean Jolliffe  

---

## What this paper does

Employment transition rates estimated from household surveys are severely upward-biased when survey respondents misreport their employment status. Even a 3% misclassification probability inflates measured quarterly entry and exit rates by a factor of nearly three. This paper develops a structural EM-algorithm estimator that jointly identifies true transition rates and misclassification probabilities from three consecutive panel waves — no reinterviews or administrative data required.

Applied to the South African Quarterly Labour Force Survey (QLFS), we find:
- True quarterly entry/exit rates ≈ 3% (vs. ≈ 8% naively measured)
- Misclassification probability π ≈ 3%, robust across all model extensions
- South African employment is far more persistent than previously characterised

## Compiling the paper

TinyTeX is required. Install once via R:

```r
install.packages("tinytex")
tinytex::install_tinytex()
```

Then compile:

```bash
cd paper
./compile.sh
```

This runs `pdflatex → bibtex → pdflatex → pdflatex` and produces `paper/paper.pdf`. The compile script uses `~/Library/TinyTeX/bin/universal-darwin/pdflatex` on macOS.

The paper ingests all results tables directly from the model output folders via `\input{}` — no manual copying needed. Tables are regenerated by re-running each model's estimation pipeline (see below).

---

## Reproducing the results

Each model subfolder is self-contained. Run them in any order; outputs land in `<subfolder>/output/`.

### 1. Baseline model (Tables 2–3 in paper)

```r
# Estimate all 6 model variants
source("EM-baseline/estimate_baseline_pipeline.R")

# Bootstrap standard errors
source("bootstrap_pipeline.R")   # or EM-baseline's own bootstrap script

# Build tables
source("build_tables.R")
```

### 2. Baseline extensions (Tables 4–6)

```r
source("EM-baseline-ext/estimate_extensions_pipeline.R")
# Tables are built by build_tables.R above
```

### 3. AR(2) model (Tables 7–8)

```r
source("EM-AR2/estimate_pipeline.R")
```

### 4. Tenure contamination model (Tables 9–11)

```r
source("EM-tenure/estimate_pipeline.R")
```

### 5. Descriptive statistics table (Table 1)

```r
source("paper/build_descriptive_table.R")
# Writes paper/output/table_descriptive.tex
```

## Data

The raw QLFS panel data (`data/raw/df_qlfs_A.rds`) is not tracked in this repository. Contact the authors for access. Processed datasets in `data-use/` are also excluded from version control.

Data ingestion scripts are in `scripts/`:
- `ingest_data_3waves_SA.R` — builds three-wave linked triads
- `ingest_data_4waves_SA.R` — builds four-wave linked triads (for AR(2))
