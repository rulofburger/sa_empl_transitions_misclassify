Part I: The Problem

Observed vs. True Employment

  • Panel surveys observe employment status s_t \in \{0, 1\} at quarterly waves t \in \{1,2,3\}
  • True (latent) status is h_t \in \{0,1\} — but we never see it directly
  • Employment states are misclassified with probability \pi:

P(s_t = a \mid h_t = b) = \begin{cases} 1 - \pi & \text{if } a = b \\ \pi & \text{if } a \neq b \end{cases}

  • We also observe tenure g_t \geq 0 (when s_t = 1) and nonemployment duration category k_t (when s_t = 0)

The Key Question

If someone is reported as employed → nonemployed → employed, did they really change status, or is the middle wave a misclassification?

Tenure can help answer this.

If s = (1, 0, 1) and g_3 \approx g_1 + 6 months, the person was likely continuously employed — the middle wave was misclassified.

Part II: Base EM Tenure Model

Latent Histories

The latent three-period history H = (h_1, h_2, h_3) has 2^3 = 8 possible values.

The Markov prior gives the probability of each history:

p(H = h) = \alpha^{h_1}(1-\alpha)^{1-h_1} \prod_{t=2}^{3} \theta_1^{\mathbb{1}\{h_{t-1}=1, h_t=1\}} (1-\theta_1)^{\mathbb{1}\{h_{t-1}=1, h_t=0\}} \theta_0^{\mathbb{1}\{h_{t-1}=0, h_t=1\}} (1-\theta_0)^{\mathbb{1}\{h_{t-1}=0, h_t=0\}}

Parameter Meaning
\alpha Initial employment probability
\theta_1 Employment continuation probability
\theta_0 Entry rate (into employment)
\pi Misclassification rate

Deterministic Tenure Clocks

Given a latent history h, tenure evolves deterministically on the quarterly grid:

  • Continuation (h_{t-1} = h_t = 1): tenure increments by \Delta = 0.25 years (3 months)
  • Start (h_{t-1} = 0, h_t = 1): tenure resets

Example

If h = (1, 1, 1) — three consecutive quarters of true employment:

g_1^* = T_g, \quad g_2^* = T_g + 0.25, \quad g_3^* = T_g + 0.50

where T_g \sim \text{Exp}(\lambda_g) is the spell-elapsed time at wave 1.

Measurement Model (Base)

The base model adds Gaussian noise to tenure observations:

  • Continuation increment: \Delta^g_t = (g_t - g_{t-1}) - 0.25 \sim N(0, 2\sigma_g^2)
  • Spell starts: g_t \sim \text{EMG}(\lambda_g, \sigma_g^2) (Exponential-Modified Gaussian)
  • Misclassified waves: draw from the population marginal \text{EMG}(\lambda_g, \sigma_g^2)

Parameters: \Theta = (\alpha, \theta_0, \theta_1, \pi, \sigma_g^2, \lambda_g, \lambda_d) — 7 free parameters.

Observed-Data Likelihood

Each individual’s likelihood sums over all 8 latent histories — we don’t know which one generated the data:

L_i(\Theta) = \sum_{h \in \mathcal{H}} \underbrace{p(h \mid \alpha, \theta_0, \theta_1)}_{\text{Markov prior}} \cdot \underbrace{\prod_{t=1}^{3} q_{s_{it}, h_t}(\pi)}_{\text{state misclassification}} \cdot \underbrace{\prod_{t=1}^{3} \ell_t(y_{it} \mid h; \lambda_g, \lambda_d, \sigma_g^2)}_{\text{duration emissions}}

The log of a sum is hard to maximise directly — the \log cannot be pushed inside the \sum_h.

The observed-data log-likelihood is:

\ell(\Theta) = \sum_{i=1}^{N} w_i \log \left[ \sum_{h \in \mathcal{H}} p(h \mid \Theta) \cdot p(y_i \mid h; \Theta) \right]

This is a mixture log-likelihood: the \log sits outside the sum over latent histories, making direct optimisation difficult.

The EM Strategy

The EM algorithm sidesteps the \log-of-sum problem by introducing responsibilities — posterior probabilities of each latent history given the observed data.

E-step: Compute responsibilities using Bayes’ rule:

\gamma_{ih} = P(H_i = h \mid y_i; \Theta^{\text{old}}) = \frac{p(h \mid \Theta^{\text{old}}) \cdot p(y_i \mid h; \Theta^{\text{old}})}{\sum_{h'} p(h' \mid \Theta^{\text{old}}) \cdot p(y_i \mid h'; \Theta^{\text{old}})}

Each \gamma_{ih} is a number between 0 and 1 telling us: given the current parameter estimates and this individual’s data, how likely is it that their true history is h?

Note that \sum_h \gamma_{ih} = 1 for each individual — the responsibilities form a probability distribution over histories.

From Observed to Complete Data

Key insight: if we knew the true history z_{ih} = \mathbb{1}\{H_i = h\}, the log-likelihood would be:

\log L_c(\Theta) = \sum_{i=1}^{N} \sum_{h \in \mathcal{H}} w_i z_{ih} \left[ \log p(h \mid \Theta) + \sum_t \log q_{s_{it}, h_t}(\pi) + \sum_t \log \ell_t(\cdot) \right]

Now the \log is inside — applied to each individual term, not to a sum. This is easy to maximise!

The EM trick: replace the unknown indicators z_{ih} with their expected values under the current parameters — which are exactly the responsibilities \gamma_{ih}:

\mathbb{E}[z_{ih} \mid y_i; \Theta^{\text{old}}] = \gamma_{ih}

So the E-step computes \gamma_{ih}, and the M-step maximises \log L_c with z_{ih} replaced by \gamma_{ih}.

M-Step: Independent Blocks

With \gamma_{ih} in hand, the complete-data log-likelihood decomposes into independent additive blocks:

Q(\Theta \mid \Theta^{\text{old}}) = \underbrace{\sum_{i,h} w_i \gamma_{ih} \log p(h \mid \alpha, \theta_0, \theta_1)}_{\text{Block 1: Markov prior}} + \underbrace{\sum_{i,h} w_i \gamma_{ih} \sum_t \log q_{s_{it},h_t}(\pi)}_{\text{Block 2: Misclassification}} + \underbrace{\sum_{i,h} w_i \gamma_{ih} \sum_t \log \ell_t(\cdot)}_{\text{Block 3: Duration emissions}}

Each block depends on different parameters, so they can be maximised independently:

Block Parameters Update
Markov prior \alpha, \theta_0, \theta_1 Weighted frequency ratios of transitions
Misclassification \pi Weighted fraction of s_{it} \neq h_t
Duration emissions \sigma_g^2, \lambda_g, \lambda_d Weighted MLE from duration data

Iterate E-step → M-step until \ell(\Theta) converges. Monotonic convergence is guaranteed by the EM theorem.

Part III: Why the Base Model Failed

Three Empirical Facts

Diagnostic analysis of the South African QLFS reveals three problems with the Gaussian measurement model:

Diagnostic Share
E→E increments exactly +3 months 63.2%
E→E increments off by > 12 months 18.7%
Fresh starts with tenure > 12 months 36.7%
s=(1,0,1) with g_3 \approx g_1 + 6 mo 27.4%
s=(1,0,1) with g_3 \leq 3 mo (fresh start) 18.3%

Key insight: The tenure increment distribution is bimodal — a huge point mass at exactly +3 months, plus a heavy-tailed residual.

This is a mixture, not a Gaussian.

Fact 1: Tenure is Not Gaussian

63.2% of E→E continuation increments are exactly +3 months. The Gaussian MLE for \sigma_g^2 collapses to essentially zero.

Fact 2: Tenure Corroborates Misclassification

State pattern s = (1, 0, 1): purple dots on the dashed line (g_3 = g_1 + 6 mo) suggest continuous employment — the middle wave is misclassified.

Fact 3: Impossible Fresh Starts

36.7% of within-panel fresh starts (s_{t-1}=0, s_t=1) report tenure > 12 months. A genuine job entry cannot have tenure exceeding \Delta = 3 months.

The Collapse Problem

What happens when we estimate the base EM tenure model?

  1. \sigma_g^2 collapses to ~0: The 63.2% exact increments overwhelm the Gaussian MLE
  2. \pi inflates to ~26%: With \sigma_g^2 \approx 0, the model has no way to explain non-exact tenure except by declaring misclassification
  3. Transition rates inflate: High \pi drives up implied true transitions

The root cause: Tenure reports that are wrong (recall error, rounding) get absorbed entirely into \pi, because the model has no separate channel for tenure measurement error.

The fundamental problem

The base model forces all tenure inconsistency through \pi (state misclassification). It cannot distinguish between:

  • The employment state being wrong (\pi)
  • The tenure report being wrong (no parameter for this!)

Part IV: The Contamination (\varepsilon) Model

The Key Idea

Replace the Gaussian measurement model with a point-mass + Exponential contamination mixture.

Each tenure observation is independently:

g_t \mid h, m_t = \begin{cases} g_t^*(h) & \text{if } m_t = 0 \quad \text{(clean: probability } 1 - \varepsilon\text{)} \\ \text{Exp}(\lambda_g) & \text{if } m_t = 1 \quad \text{(contaminated: probability } \varepsilon\text{)} \end{cases}

  • Clean (m_t = 0): tenure equals the deterministic clock value exactly (point mass)
  • Contaminated (m_t = 1): tenure is an independent draw from \text{Exp}(\lambda_g), unrelated to the clock

\varepsilon captures recall error, year-rounding, respondent substitution — any mechanism producing a tenure value unrelated to the true clock.

Two Separate Error Channels

This is the crucial distinction

State wrong Tenure wrong
Base model \pi \sigma_g^2 (collapses)
Contamination model \pi \varepsilon

The contamination model has two independent error parameters:

  • \pi: the employment state is misclassified
  • \varepsilon: the tenure report is contaminated (but the state may be correct!)

This allows someone to be truly employed (h_t = 1) with correct state report (s_t = 1) but wrong tenure (m_t = 1).

Spell-Pair Joint Emission

The key structural innovation: instead of evaluating each wave’s tenure independently, evaluate all observed tenure within a latent employment spell jointly.

A spell-pair arises when a single latent employment spell spans multiple survey waves but tenure is only observed at some of them — e.g. under h = (1,1,1) with s = (1,0,1), waves 1 and 3 are a “pair” of tenure observations from the same underlying spell. These two flanks are structurally linked by the deterministic clock: g_3^* = g_1^* + 2\Delta.

For a spell [a, b] with observed waves \mathcal{O} = \{t_1, \ldots, t_K\}:

\ell_g^{\text{spell}} = \sum_{\mathbf{m} \in \{0,1\}^K} \left[ \prod_{t \in \mathcal{O}} \varepsilon^{m_t} (1-\varepsilon)^{1-m_t} \right] f(\{g_t\} \mid \mathbf{m}, h)

This sums over all 2^K contamination patterns. The conditional density f depends on which waves are clean (pinned to the clock) vs. contaminated (independent Exp draws).

The Conditional Density f

The density f(\{g_t\} \mid \mathbf{m}, h) is obtained by marginalising out the latent spell-start time T_g \sim \text{Exp}(\lambda_g):

If at least one wave is clean (\exists\, t : m_t = 0), then T_g is pinned by the earliest clean wave. Let t^* be the first clean wave. Then T_g = g_{t^*} - (t^* - a)\Delta, and:

  • Each clean wave t \neq t^*: contributes a point-mass check — does g_t = g_{t^*} + (t - t^*)\Delta?
  • The pinning wave t^*: contributes \lambda_g e^{-\lambda_g [g_{t^*} - (t^* - a)\Delta]} (Exp density of T_g)
  • Each contaminated wave: contributes \lambda_g e^{-\lambda_g g_t} (independent Exp draw)

If all waves are contaminated (\mathcal{C} = \emptyset), T_g integrates out to 1 and every wave contributes an independent \text{Exp}(\lambda_g) density:

f(\{g_t\} \mid \mathbf{m} = \mathbf{1}, h) = \prod_{t \in \mathcal{O}} \lambda_g e^{-\lambda_g g_t}

Example: The K=2 Case — Setup

State pattern s = (1, 0, 1), latent history h = (1, 1, 1) — continuous employment, middle wave misclassified.

The spell runs [1, 3] but tenure is observed only at waves 1 and 3 (the flanks of the spell). The spell start is a = 1, so T_g = g_1^* and g_3^* = T_g + 2\Delta = g_1^* + 0.5 yr.

The four contamination patterns (m_1, m_3) yield structurally different densities:

Example: The K=2 Case — Four Densities

(m_1, m_3) = (0, 0) — Both clean. T_g is pinned by g_1, so g_3 must equal g_1 + 0.5: f = \lambda_g e^{-\lambda_g g_1} \cdot \mathbb{1}\{g_3 = g_1 + 2\Delta\}

(m_1, m_3) = (0, 1) — Wave 1 clean, wave 3 contaminated. T_g = g_1, and g_3 is an independent Exp draw: f = \lambda_g e^{-\lambda_g g_1} \cdot \lambda_g e^{-\lambda_g g_3} = \lambda_g^2 e^{-\lambda_g(g_1 + g_3)}

(m_1, m_3) = (1, 0) — Wave 1 contaminated, wave 3 clean. Now g_3 pins T_g: T_g = g_3 - 2\Delta, so wave 1 is an independent Exp draw and wave 3 determines the clock: f = \lambda_g e^{-\lambda_g g_1} \cdot \lambda_g e^{-\lambda_g(g_3 - 2\Delta)} = \lambda_g^2 e^{-\lambda_g(g_1 + g_3 - 2\Delta)}

(m_1, m_3) = (1, 1) — Both contaminated. T_g integrates out; both are independent Exp draws: f = \lambda_g e^{-\lambda_g g_1} \cdot \lambda_g e^{-\lambda_g g_3} = \lambda_g^2 e^{-\lambda_g(g_1 + g_3)}

Example: The K=2 Case — Distinguishing the Patterns

Notice that (0,1) and (1,1) produce the same functional form \lambda_g^2 e^{-\lambda_g(g_1+g_3)}, but (1,0) has a shift of +2\Delta in the exponent:

\ell_g^{\text{spell}} = \underbrace{(1-\varepsilon)^2 \lambda_g e^{-\lambda_g g_1} \cdot \mathbb{1}\{g_3 = g_1 + 2\Delta\}}_{\text{both clean: point mass}} + \underbrace{\big[(1-\varepsilon)\varepsilon + \varepsilon^2\big] \lambda_g^2 e^{-\lambda_g(g_1+g_3)}}_{(0,1) \text{ and } (1,1): \text{same form}} + \underbrace{\varepsilon(1-\varepsilon) \lambda_g^2 e^{-\lambda_g(g_1+g_3-2\Delta)}}_{(1,0): \text{shifted by } e^{+\lambda_g \cdot 2\Delta}}

When g_3 = g_1 + 0.5 yr: the all-clean pattern fires its point mass → strong evidence for continuous employment → pushes \gamma toward h = (1,1,1) → increases implied \pi.

When g_3 \neq g_1 + 0.5 yr: the point-mass term is zero, but the three continuous terms remain active. The (1,0) term is distinguished from the others by the shift factor e^{\lambda_g \cdot 2\Delta}.

Identifying \varepsilon

\varepsilon is identified from the empirical fraction of tenure observations that are exactly clock-consistent.

Source 1 — Adjacent E→E pairs (s_{t-1} = s_t = 1, h_{t-1} = h_t = 1):

  • These are consecutive employed waves where both tenure values are observed.
  • If m_t = 0 (clean), the increment g_t - g_{t-1} must equal exactly \Delta = 0.25 yr.
  • The indicator \mathbb{1}\{g_t - g_{t-1} = \Delta\} is Bernoulli with mean 1 - \varepsilon.
  • Empirically, 63.2% satisfy this → \hat{\varepsilon}_{\text{MoM}} = 1 - 0.632 \approx 0.37.

Source 2 — Two-wave bridges (s = (1, 0, 1) under h = (1, 1, 1)):

  • These are panels where the individual is observed as employed at waves 1 and 3 but nonemployed at wave 2, yet is truly employed throughout — the wave-2 nonemployment is a misclassification.
  • Tenure is observed only at the two “flanks” (waves 1 and 3). If both are clean, g_3 = g_1 + 2\Delta.
  • The indicator \mathbb{1}\{g_3 = g_1 + 2\Delta\} is Bernoulli with mean (1-\varepsilon)^2 (both waves must be independently clean).
  • Empirically, 27.4% satisfy this → \hat{\varepsilon}_{\text{MoM}} = 1 - \sqrt{0.274} \approx 0.48.

The EM estimate combines both sources via responsibility-weighted averaging, yielding \hat{\varepsilon} \approx 25\% (lower than MoM because the EM correctly accounts for genuine transitions).

Identifying \pi — The Corroboration Channel

In the base model (and the simple model without tenure), \pi is identified only from the frequencies of the 8 observed state patterns s = (s_1, s_2, s_3) — i.e. from state-Markov violations alone.

The contamination model adds a second identification channel: tenure-flank consistency within spell-pairs.

What is a spell-pair?

A “spell-pair” is a pair of tenure observations that belong to the same latent employment spell but are separated by one or more waves where the individual reports nonemployment. For example, under s = (1,0,1) with h = (1,1,1), waves 1 and 3 are a spell-pair — two tenure “flanks” of the same continuous job spell.

How tenure flanks identify \pi:

  • When s = (1,0,1) and g_3 \approx g_1 + 0.5 yr (27.4% of cases): the spell-pair point mass fires → the posterior \gamma is pushed strongly toward h = (1,1,1) → this counts wave 2 as a misclassification, contributing to \hat{\pi}.
  • When s = (1,0,1) and g_3 \leq 3 months (18.3% of cases): tenure looks like a fresh start → consistent with h = (1,0,1) (genuine transition) → does not contribute to misclassification.
  • When s = (0,1,0) with matching timegap categories k_1 = k_3 (63.7% of cases): similar logic — timegap consistency pushes \gamma toward h = (0,0,0).

The result: \hat{\pi} is identified from both state-Markov violations and tenure-flank consistency. Tenure data corroborates and refines the misclassification estimate.

How \varepsilon Affects the Posterior

\varepsilon enters \gamma_{ih} only through the spell-pair emission \ell_g^{\text{spell}} — it does not appear in the Markov prior or in singleton-spell emissions.

Consider s = (1,0,1) with two competing histories:

h = (1,1,1) (spell-pair) h = (1,0,1) (two singletons)
Emission \ell_g^{\text{spell}} from Eq. — depends on \varepsilon \lambda_g e^{-\lambda_g g_1} \cdot \lambda_g e^{-\lambda_g g_3} — no \varepsilon

\varepsilon controls the discrimination power of tenure evidence:

Low \varepsilon (most reports are clean):

  • Clock-consistent flanks → point mass fires → \gamma_{(1,1,1)} very high
  • Clock-inconsistent flanks → point mass = 0, contamination terms are small → \gamma_{(1,1,1)} very low
  • Tenure strongly informs \pi

High \varepsilon (many reports are contaminated):

  • Clock-consistent → point mass still dominates but weighted by smaller (1-\varepsilon)^2
  • Clock-inconsistent → contamination terms are larger → \gamma_{(1,1,1)} increases (tenure inconsistency is “explained away” as contamination)
  • Tenure weakly informs \pi; Markov prior dominates

Note

\varepsilon governs how informative tenure is; \pi governs how much misclassification there actually is. The EM finds the (\varepsilon, \pi) pair that jointly explains both the clock-consistency rate and the state-pattern frequencies.

Worked Example: Base Model

Consider an individual with s = (1,1,1) and tenure g = (1.0,\; 5.0,\; 1.5) years.

Under h = (1,1,1) (continuous employment), the clock predicts: g_1^* = T_g, \quad g_2^* = T_g + 0.25, \quad g_3^* = T_g + 0.50

The observed increments are:

  • g_2 - g_1 = 4.0 years (should be +0.25) — off by 3.75 years
  • g_3 - g_2 = -3.5 years (should be +0.25) — off by 3.75 years

With \sigma_g^2 \approx 0, the Gaussian increment density assigns near-zero likelihood to these deviations under h = (1,1,1).

The model is forced to declare h = (1,0,1): the individual truly left employment at wave 2 and re-entered at wave 3. This requires:

  • A true transition 1 \to 0 between waves 1–2
  • A true transition 0 \to 1 between waves 2–3
  • A misclassification at wave 2 (s_2 = 1 but h_2 = 0)

→ Both \pi and transition rates are inflated to accommodate tenure inconsistency.

Worked Example: Contamination Model

Same individual: s = (1,1,1), tenure g = (1.0,\; 5.0,\; 1.5) years.

Under h = (1,1,1), the spell emission sums over 2^3 = 8 contamination patterns. Consider the pattern \mathbf{m} = (0, 1, 0) — waves 1 and 3 clean, wave 2 contaminated:

  • Wave 1 (m_1 = 0, clean): T_g = g_1 = 1.0 yr. Density: \lambda_g e^{-\lambda_g \cdot 1.0} ✓
  • Wave 2 (m_2 = 1, contaminated): g_2 = 5.0 is just an independent Exp draw. Density: \lambda_g e^{-\lambda_g \cdot 5.0} ✓
  • Wave 3 (m_3 = 0, clean): must satisfy g_3 = g_1 + 2\Delta = 1.5 yr. ✓ It does!

So the clock-consistency check passes for waves 1 and 3 (they are 0.5 yr apart, exactly 2\Delta), and wave 2’s outlier tenure is absorbed by the contamination branch.

The key difference

No state misclassification is needed. The individual is truly employed throughout (h = (1,1,1)), correctly reported as employed (s = (1,1,1)), but wave 2’s tenure is simply a bad report (m_2 = 1). This keeps \pi and transition rates at sensible levels.

Key Findings

Contamination rate

  • \hat{\varepsilon} \approx 25\% — stable across specifications
  • Below method-of-moments (37–48%), because the EM accounts for genuine transitions explaining some non-exact increments

Misclassification rate

  • \hat{\pi} \approx 10\% — substantially above the simple model’s 3%
  • The corroboration channel: tenure flanks provide direct evidence that observed (1 \to 0 \to 1) sequences are often misclassified continuous employment

Transition rates

  • Entry: \hat{\theta}_0 = 4.1\%; Exit: 1 - \hat{\theta}_1 = 4.3\%
  • Between naïve (8.3%) and simple ME (2.9%)
  • Naïve overstates transitions (counts misclassifications as transitions)
  • Simple ME understates them (lacks tenure information to properly identify \pi)

Model fit

  • Consistent with descriptive evidence
    • 36.7% impossible fresh starts → \pi should be well above 3%
    • 63.2% exact increments → \varepsilon should be below 37%

Summary

What the contamination model achieves

  1. Eliminates \sigma_g^2 collapse — no Gaussian noise parameter to degenerate
  2. Separates state vs. tenure error — \pi for states, \varepsilon for tenure
  3. Tenure corroborates \pi — spell-pair flanks provide a new identification channel
  4. Plausible estimates — \pi \approx 10\%, consistent with descriptive evidence
